queue is an ordered collection of itmes in which items can be inserted from one position i.e rear 
and remove from another position called as front thus the queue operates on FIFO principle
or FCFS principle
IMP Methods are :
1)size() -> To know the no. of elements in queue
2)offer(object o) -> To add/insert object o in queue
3)poll() -> to remove element from queue 
4)preek() -> to inspect the element to be removed
5) isempty() -> to check whether queue is empty or not
there are several types of queue
a) linear queue
b) circular queue
c) dequeue(double ended queue)
d)priority queue

HEAP is a binary tree which staisfies the heap properties and which can be 
represented using an array
There are two types of heap 
1) minimum heap 
2) maximum heap 
in minimum heap the value of the parent node should be less than equal to child node. 
in maximum heap the value in parent node should be greater than or equal to value in child node 
also note that in minimum heap the root contains smallest value from tree where as in max heap it 
contains largest value
