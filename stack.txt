stack is a data structure in which the elements are inserted from a position called as top and
removed from same position thus the stack operates on LIFO principle 
IMP Methods of stack are 
1) size() -> To know the no of elements in stack 
2) push(object o) -> To push/insert the Object o in stack 
3) pop() -> To remove the element at the top of stack 
4) peek() -> To inspect the element at the top of stack()
5) isEmpty() -> To check whether the stack is empty or not. Returns true if empty otherwise false
